# School District Budget Forecasting & Fiscal Sustainability Analytics

**For:** ESO Consultants LLC — Financial Planning & Budget Analyst
(client: Phoenix Central School District)
**Author:** Bhupesh Chandra Dimri
**Stack:** Python 3, pandas, NumPy, scikit-learn, matplotlib

## One-liner

A budget analyst's whole workflow for a public school district — variance
analysis, multi-year revenue/expenditure forecasting, fund-balance trajectory
with a rule-based sustainability score, staffing-cost driver analysis, a
scenario engine, and variance anomaly detection — built on synthetic data.

## ⚠️ Synthetic data — read first

All data in this project is **synthetic**, generated by `src/data_gen.py`
with a seeded, auditable process. **Nothing here is the real finances of
Phoenix Central School District or any real district.** Fund categories
follow standard governmental fund-accounting structure as a labelled
[ASSUMPTION]; this is NOT Wincap expertise and must not be presented as such.

## How to run

```bash
python run_all.py            # data -> analysis -> forecast -> charts + reports/metrics.json
python -m tests.test_all     # test suite (prints a runtime "N passed" line)
python build_docs.py         # rebuilds the 10-page report and 10-slide deck
```

## Headline results (from `reports/metrics.json`)

- **Forecast holdout (FY2023–25):** revenue naive MAPE 2.88% beats linear
  trend 9.90% — a federal-aid cliff breaks every trend; expenditure linear
  trend wins at 0.98%.
- **Sustainability score:** 55.8/100 — band **Watch**. Fund balance 8.46% of
  budget, but structural balance −4.7% and reserves falling ~$1.9M/year.
- **Base case:** fund balance turns negative in FY2027, −$10.3M by FY2028.
  Restoring historical ~2.2%/yr revenue growth would add ~$5.9M cumulatively
  and still leave it negative — a structural gap, not a forecasting artefact.
- **Staffing:** benefit costs grow 7.41%/yr vs salary 2.93%/yr; benefit rate
  is the top cost driver (OLS R² 0.999).
- **Scenarios:** state aid ±5% is the biggest lever (±$2.66M on the FY2028
  balance).
- **Anomaly detection:** z-score rule F1 0.800 beats Isolation Forest 0.571.
  The first threshold tested (|z| > 2.5) missed all three injected
  anomalies — reported as a finding about small-sample z-scores.
